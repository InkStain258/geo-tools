# 高中地理交互工具网站 — 产品需求文档（PRD）

## 项目信息

| 字段 | 内容 |
|------|------|
| Language | 中文 |
| Programming Language | Vite + React + TypeScript + Tailwind CSS + MUI |
| Project Name | `geo-tools` |
| 原始需求 | 开发一个高中地理交互工具网站，包含14个地理学习工具，纯静态部署至 GitHub Pages，零后端依赖 |

---

## 1. 产品目标

1. **交互式知识内化**：将高中地理抽象概念（洋流、大气环流、日照等）转化为可操作的视觉交互，帮助学生从"死记硬背"转向"理解运用"
2. **一站式地理工具集**：覆盖自然地理、大气气候、天文运动、人文地理四大模块，成为高中生地理学习的首选辅助平台
3. **零门槛即时使用**：纯静态部署，无需注册/登录，打开即用，支持图表与示意图一键导出 PNG 用于笔记与作业

## 3. 需求池

### 自然地理（3个工具）

| 模块 | 功能名 | 优先级 | 验收标准 |
|------|--------|--------|----------|
| 自然地理 | 地形剖面生成器 | P0 | 用户可在等高线图上绘制A-B剖面线；实时生成对应地形剖面图；支持导出PNG；剖面线可清除重绘 |
| 自然地理 | 河流流域交互图 | P1 | 点击流域区域展示分水岭、干支流信息；含流量季节变化柱状图（Chart.js）；支持导出PNG |
| 自然地理 | 洋流动态模拟 | P1 | 展示全球主要寒暖流运动方向动画；可暂停/播放；点击洋流标注对气候与渔场的影响文字 |

### 大气与气候（3个工具）

| 模块 | 功能名 | 优先级 | 验收标准 |
|------|--------|--------|----------|
| 大气与气候 | 气候类型判断器 | P0 | 用户可输入12个月气温+降水数据；自动判断气候类型；逐步展示判断推理过程（以气温定带→以降水定型） |
| 大气与气候 | 大气环流可视化 | P1 | 展示三圈环流+气压带风带动画；可拖动季节滑块查看气压带偏移；标注环流名称 |
| 大气与气候 | 锋面天气模拟 | P1 | 支持冷锋/暖锋/准静止锋选择；播放过境动画（云系变化、温度变化曲线）；支持导出PNG |

### 天文与地球运动（3个工具）

| 模块 | 功能名 | 优先级 | 验收标准 |
|------|--------|--------|----------|
| 天文与地球运动 | 日照图计算器 | P0 | 拖动日期滑块实时渲染晨昏线位置；标注太阳直射点经纬度；计算指定纬度昼夜长短；支持导出PNG |
| 天文与地球运动 | 时区与地方时计算器 | P1 | 输入已知地点经度和时刻；计算目标经度对应时刻；支持区时/地方时切换；显示计算过程 |
| 天文与地球运动 | 正午太阳高度角计算器 | P1 | 输入纬度+日期；计算正午太阳高度角；动态展示高度角示意图；支持导出PNG |

### 人文地理（3个工具）

| 模块 | 功能名 | 优先级 | 验收标准 |
|------|--------|--------|----------|
| 人文地理 | 工业区位分析工具 | P1 | 选择工业类型（劳动/技术/资源/市场导向等）；展示区位因素权重雷达图；支持导出PNG |
| 人文地理 | 农业区位图解 | P1 | 选择农业类型+区域（东北/南方/西北/西藏等案例）；展示自然/人文因素交互图；支持导出PNG |
| 人文地理 | 城市等级服务圈 | P2 | 可视化中心地理论；动态展示城市等级嵌套关系；可拖动节点调整布局 |

### 辅助学习工具（2个工具）

| 模块 | 功能名 | 优先级 | 验收标准 |
|------|--------|--------|----------|
| 辅助学习 | 图表判读训练 | P2 | 给出气候统计图/等值线图；提供步骤化判读引导；含答案解析 |
| 辅助学习 | 地理计算公式速查 | P2 | 分类展示时差/距离/坡度/人口密度等公式；每个附带交互例题（输入参数即时计算） |

## 4. UI 设计规范

### 色彩体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色（Primary） | `#2E7D32`（地理绿） | 体现自然/地理学科属性 |
| 辅色（Secondary） | `#1565C0`（海洋蓝） | 水文、气候模块辅助色 |
| 强调色（Accent） | `#F57C00`（日橙） | 太阳/天文模块、CTA 按钮 |
| 背景 | `#FAFAFA` | 浅灰白，减轻视觉疲劳 |
| 卡片背景 | `#FFFFFF` | 纯白卡片 |
| 文字主色 | `#212121` | 正文 |
| 文字辅助 | `#757575` | 说明文字 |

### 字体

| 场景 | 字体 | 规格 |
|------|------|------|
| 标题 | `Noto Sans SC` Bold | 24px / 20px / 16px（H1/H2/H3） |
| 正文 | `Noto Sans SC` Regular | 14px |
| 公式/代码 | `JetBrains Mono` | 14px |
| 图表标注 | `Noto Sans SC` Medium | 12px |

### 布局

- **首页**：工具卡片网格布局（Masonry），按四大模块分组，每卡片含图标+名称+一句话描述
- **工具页**：顶部工具栏（标题+导出按钮）→ 中部交互画布区 → 底部参数面板/控制面板
- **响应式**：桌面端双栏（画布+控制面板并列），移动端单栏（画布在上，控制面板在下）
- **最大内容宽度**：1200px，居中

### 动效风格

- **页面切换**：Framer Motion `fade + slide`，duration 200ms
- **工具交互反馈**：微动效（hover 放大 1.02、按钮 ripple）
- **地理动画**：洋流/锋面/环流使用路径动画，帧率 60fps，支持暂停/播放/速度调节
- **滑块操作**：实时渲染，无延迟感（requestAnimationFrame 驱动）
- **导出**：导出时短暂 loading 态，成功后 toast 提示

## 5. 待确认问题

| # | 问题 | 影响范围 | 建议 |
|---|------|----------|------|
| 1 | 等高线地形图的底图数据来源？是否需要内置多组预设地形，还是用户可自定义等高线？ | 地形剖面生成器 | 先内置 3-5 组高中常见地形预设，后续再考虑自定义 |
| 2 | 气候类型判断器是否需要覆盖所有高中阶段气候类型（10种），还是先覆盖高频考查的6种？ | 气候类型判断器 | P0 先覆盖6种高频类型（热带雨林/草原/沙漠/季风、亚热带季风、温带海洋性），P1 补全 |
| 3 | 洋流动态模拟是否需要支持用户拖拽洋流路径，还是仅展示固定动画？ | 洋流动态模拟 | 先做固定路径动画+点击查看详情，降低复杂度 |
| 4 | 城市等级服务圈的节点拖动是否需要持久化布局？是否需要吸附对齐？ | 城市等级服务圈 | P2 阶段不需要持久化和吸附，拖动即时反馈即可 |
| 5 | 导出 PNG 的分辨率和质量要求？是否需要支持 SVG 导出？ | 全局 | 默认 2x 分辨率导出 PNG，暂不支持 SVG |

## 附录：技术约束摘要

| 约束项 | 说明 |
|--------|------|
| 部署方式 | 纯静态，GitHub Pages，零后端 |
| 技术栈 | Vite + React + TypeScript + Tailwind CSS + MUI |
| 图表库 | Chart.js（柱状图/雷达图）+ D3.js（地理投影/复杂可视化） |

| 构建产物 | `dist/` 目录，支持 `vite build --base=/repo-name/` |
